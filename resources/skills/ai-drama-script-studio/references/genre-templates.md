# 三大剧种特化剧本规范与改写差异

在 `bible`（定调与资产设计）与 `script`（撰写完整分集剧本）阶段读取。不同剧种的镜头语言、台词密度与音效作用完全不同，必须按选定剧种执行。

---

## 剧种 1：`ai-drama`（常规仿真人 / 写实 AI 短剧 · 默认深度适配 MiniMax-H3）

适配红果「AI 剧」热播赛道（年代穿越创业、乡土/美食种田、历史团队季播、都市轻逆袭/萌宝/情感），并针对 **MiniMax-H3（Hailuo 3）** 全模态特性深度优化：

### MiniMax-H3（Hailuo 3）生产特性与剧本写法对齐
1. **善用 5–15 秒原生音画同步长单镜（告别旧式 3 秒碎剪）**：
   - MiniMax-H3 原生支持 **5–15 秒** 2K 9:16 竖屏输出，且同步生成**带中文自然口型的对白 + 立体声环境底噪**。
   - **剧本写法**：一集 60–90 秒拆为 **8–14 个连贯音画镜**（每镜 5–12 秒）即可，一个镜内可以演完“一句短对白 + 对手微表情变脸 + 一句回怼”，表演连贯性远胜强行切碎的 25 个哑巴镜头。
2. **原生口型对白纪律**：
   - 单镜内角色自然开口的中文台词建议控制在 **12–35 字**（5–10 秒刚好念得从容有情绪、口型稳、竖屏字幕不挡脸）；
   - 严禁让角色在一个镜头里一口气念 60 字长篇大论——拆成正反打双镜，或用**物件特写/对方反应镜配画外音（VO）**过渡。
3. **多人同框口型隔离铁律（MiniMax-H3 实操防崩关键）**：
   - 当一个镜头内同时出现 2 名及以上角色时，画面描述里**必须显式写明「谁张嘴清晰发声、其余同框角色一律闭嘴静态」**（例如：`@CHAR-01 张嘴清晰发声；@CHAR-02 僵立，@CHAR-02 闭嘴静态`），彻底避免原生影音模型多人同时乱动嘴或串音。
4. **红果 40× 分成与零 BGM / 审核避险规范**：
   - **旁白/OS 严控 ≤ 20%**：以多角色现场口型对白推进剧情，确保整季不超过 2 集出现旁白/心理独白超 20%，保住红果 **40×** 画风分成系数（防降档到 `10×` 动态解说漫剧）；
   - **单季时长规划**：常规 30 集 × 75–85 秒 ≈ 38–42 分钟（同时过红果 ≥20 分钟首传门槛与「AI短剧创作计划」≥30 分钟终极评奖线）；长线冲框架合作可按 60–120 集分季推进；
   - **零 BGM 纯人声 + 自然动作音效（Foley）**：若直投红果个人版权方，优先采用“纯中文口型对白 + 精准物理 Foley 音效”（拍桌、碎瓷、盖章、计算器嘀嘀、铁尺哐当、油锅滋啦），脚本中不写 `BGM/配乐/旋律/乐器` 等词，彻底规避音乐版权下架风险；
   - **审稿安全底线**：去封建迷信（玄幻/规则类用“能量/算力/契约”等架空概念替代鬼神占卜）、零流血暴力擦边、剧名/简介禁用“爆款/绝密/最强/第一/逆天/秒杀”等夸张营销词。
5. **12 资产槽位与封闭管道控漂移（最多 9 图 / 3 视频 / 3 音频）**：
   - 剧本书写时用固定标签引用资产（`@CHAR-01/@LOC-01/@PROP-01/@VOICE-01` 或 `char_01/scene_01/prop_01/voice_char_01`），**单镜主体 ≤ 2–4 人**；
   - 30 集左右连载尽量将核心露脸角色锁死在 4–6 人、核心场景锁死在 4–6 处；外部施压/新事件优先通过“固定代表人物上门 + 纸质文书/道具 + 系统弹窗/画外通知”三条管道消化，不为了过场随便新增第 7 个只露一面的 NPC。
6. **可选：批量渲染产线 `17n+5` 帧档与纯汉字对齐（自动化渲染时启用）**：
   - 若项目直连严格按帧批渲染的 MiniMax-H3 自动化产线，可选用 `24fps` 四档精准帧网格（语速 3.8–4.2 字/秒，留 ≥0.3s 尾音），且对白中的数字/缩写写成纯中文汉字（如“三百万”“百分之五十”）：
     - A 档（快切/爆点）：`124帧`（5.17s）→ 19–21 字
     - B 档（标准嘴炮）：`175帧`（7.29s）→ 27–29 字
     - C 档（反转/宣读）：`226帧`（9.42s）→ 36–38 字
     - D 档（压轴结算）：`243帧`（10.13s）→ 39–41 字
   - 若为人工半自动生成或初稿试写，不必硬卡 `17n+5` 帧数，按 5–12 秒 / 12–35 字灵活把握即可。
7. **真实感与生活流（红果 AI 剧高分秘诀）**：
   - 写年代、职场、美食、维修、种田、审计/行业等题材时，把**具体手艺、真实账目/物价与自然 Foley 底噪**写实，让观众觉得“接地气、下饭”，同时保持爽点干脆不烧心。

### `ai-drama` 标准单集剧本格式示例

```markdown

- 本集爽点/推进：开局3秒亮绝活破轻视，集末留黑市大佬登门钩子

## 场 1｜日 · 内 · `@LOC-01` 城中村杂物间改的维修铺

**[镜01｜0-7s｜近景→特写｜`@CHAR-02` `@PROP-01`]**
- 画面：红姐双手叉腰堵在掉漆木门框里，手指戳着桌上那台外壳发黄的坏录像机，下巴微抬，眼神上下打量。
- 声音：[环境音] 巷口旧风扇咔哒响；`@CHAR-02`（泼辣快语速）：“八十五块租半个月？这破机子修不好，今晚你连被褥一起滚大街！”

- 声音：[音效] 电容落桌清脆声；`@CHAR-01`（平稳带狠劲）：“三分钟，开机。”

...

**[集末卡点｜70-75s｜特写｜`@LOC-01` 门外]**
- 画面：刚亮起的电视雪花屏突然一暗，三双沾泥黑皮鞋踩碎门口水洼停在门槛前，一只夹烟的手拍上卷帘门。
```

## 剧种 2：`comic-drama`（2D / 3D 高奇观 AI 漫剧）

适配红果「漫剧」霸榜赛道（规则怪谈、末世倒计时/公路求生、玄幻修仙系统、无限流、高概念脑洞多季连载）：

1. **首集高燃开篇结构（验证有效的“预告钩子 + 极端劣势”范式）**：
   - **0–20 秒高燃视觉预告**：开篇可直接用高质感 AI 画面快速砸出世界异象（如血瞳降临、全员头顶倒计时归零化灰、主角觉醒禁忌异能高光定格），再切回日常瞬间爆发危机；
   - **极端劣势对比**：立刻用肉眼可见的数字反差制造紧迫感（如室友剩余 12 年 / 8 年，唯独主角只剩 71 小时 59 分），紧接给出**只有主角能发现的唯一破局变量**（如异常光点/规则漏洞/神秘晶体）并在集末甩出幕后视角或反转钩子。
2. **视觉奇观优先（放大真人拍不起的爽感）**：
   - 每一集必须至少设计 **1 个强视觉奇观锚点**：如全息系统金光弹窗、头顶血条/倒计时、万米仙尸锁链、诡异伪人瞳孔裂变、末世战车升级变形、灵气爆发冲击波。
   - 把文字里的数值/规则直接写成屏幕可读的 **`[画面字幕/UI特效]`**（例如：`[血红色系统弹窗浮空：及格线60分，差1分——抹杀！]`）。
3. **旁白/对白分轨控制**：
   - **上红果冲 40× 分成**：必须把规则解释和冲突放进角色现场对话、系统播报与同伴吐槽里，压低纯旁白/心理独白至 **≤ 20%**；
   - **投抖音/中视频/推文引流**：可采用“冷峻旁白 + 角色短台词”快切解说流，旁白每句 ≤ 20 字与画面强咬合。
4. **动作场面用「蓄力定格 + 冲击特写 + 结果全景」省算力**：
   - 避免写“两人连续对招三十回合翻腾踢打”（AI 动画极易畸变），改写为：`[特写] 剑刃青光暴涨 → [极速残影切镜] 气浪震碎石柱 → [定格全景] 对手半跪吐血，身后整座祭坛一分为二`。
5. **多季化大地图留钩子**：
   - 季内每 15–25 集换一次小副本/小地图，季末必须掀开更高维度的世界真相或新强敌，天然支撑第 2 季、第 3 季持续连载。

## 剧种 3：`shadiao`（沙雕短剧 / 沙雕漫 · 双子轨实战模板）

沙雕短剧按变现阵地与制作工艺明确分为**两条子轨**，立项时先定子轨：

### 子轨 A：红果 40× 快切沙雕漫剧（竖屏 70–95 秒/集，冲高分成）
- **资产架构**：`PNG 核心主角（≤4 人）+ SVG 简约白人偶/表情包群演 + 固定切脸编号（如 FACE-01 撇嘴冷笑 / FACE-02 鼻孔喷气 / FACE-03 死鱼眼 / FACE-04 下巴砸地 / FACE-05 口水瀑布 / FACE-06 委屈红眼 / FACE-07 黑化护食）+ HTML HUD 对比贴纸`（极低算力成本，单集 1–2 个复用场景）。
- **四段秒级极速节拍（18–25 镜，每镜 2–4 秒，纯台词+心声约 320–400 字）**：
  1. **`0–3s` 贴脸开局钩子**：踹门/抢物/当场羞辱 + 1 秒干脆反击，零背景铺垫；
  2. **`4–30s` 吐槽与反怼**：高频一来一回嘴炮 + 道具/规则首次显灵（对手秒切“真香”脸）；
  3. **`31–70s` 反转大打脸**：进度卡在 99.9% 制造假危机 → 群演变脸闹剧 → 意外天降破局变量；
  4. **`71–95s` 落袋与强断章**：黑白定格在冤种/反派呆滞脸上，一句俏皮吐槽或悬念音切黑屏！
- **分成保卫线**：主角“吃瓜心声/旁白”每集控制在 **3–4 句以内（总字数占比 ≤ 20%）**，其余全部用多角色口型对白推进，稳拿红果 40× 系数！

### 子轨 B：抖音 / B 站 / 推文向旁白沙雕动画（横/竖屏，2–15 分钟合集）
- **资产架构**：经典熊猫头/暴漫脸主角 + 2D 扁平场景平移切脸，或 Q 版立绘 + 白人偶群演（可首段混剪 15–20 秒高燃 AI 画面拉完播）。
- **叙事引擎**：第一人称快节奏旁白 + 电话/场景对话交错推进，允许高旁白占比（体检时传 `--allow-high-narration` 豁免 20% 告警）；用**合规趣味谐音梗**替代平台敏感词（如末世类用“丧坤”“狙鸡强”等增加笑点同时保过审）。
- **喜剧核心公式（两轨通用）**：
  - **10–15 秒必出一个「预期违背」包袱**：`一本正经铺常规套路 → 突然走向极度离谱但在本剧歪理里完全自洽的行动 → 音效骤停（刮碟/乌鸦叫/弹簧嘣）+ 毒舌神补刀`。
  - **听觉与视觉错位**：显式标出 `[方言/1.2x快嘴/播音腔]`、`[HTML HUD 贴纸/花字]` 与 `[Foley/魔性音效]`。

## 单剧原声定调与去套话红线（全剧种共用）

- **每部剧独立写 1 段「声口切片」**放入 `00_季播总案与资产表.md`，明确本剧说话节奏、方言/口癖与幽默刻度，防止连写十部剧全变成同一种AI腔。
- **严禁把小说翻译腔带进台词**（如“这不仅仅是一场交易，更是命运的博弈”“空气仿佛凝固了”）；台词必须**念出来顺嘴、有活人气**。
- **不封杀正常口语词与生活化比喻**，保留角色活生生的情绪爆点。
