在 `bible`（建资产表）、`storyboard`（按需拆镜）、`check`（脚本体检）与 `export`（导出交付）阶段读取。

---

## 1. 控算力固定资产表（防崩脸与省抽卡的命脉）

AI 短剧最大的隐藏成本不是写剧本，而是**剧本乱加人、乱换衣服、乱切新场景导致的反复抽卡与崩脸**。在 `00_季播总案与资产表.md` 中，动笔前必须锁定四大资产表，并在后续剧本中统一用 ID 引用：

| 资产前缀 | 管控上限（单季建议） | 必须锁定的视觉/声音锚点 |
|---|---|---|
| **`@CHAR-NN`**（核心角色） | 短期/沙雕 3–5 人；长线季播 5–8 人（其余一律作无脸背影路人） | 年龄、脸型气质、发型发色、**固定标志性穿搭**（如“洗白蓝工装夹克+黑框眼镜”）、标志小动作；便于对齐红果「虚拟形象管理」与 MiniMax-H3 参考图槽位 |
| **`@LOC-NN`**（复用主场景） | 4–6 个核心场景（单集严控 1–2 处主场景） | 空间布局、时代/画风质感、主色调与固定光源（如“80年代土坯院落，暖黄夕阳，墙角堆柴火”），避免每集凭空生新场地 |
| **`@PROP-NN`**（核心道具/奇观） | 2–5 件贯穿全季的核心物件 | 具象外观、发光/材质细节（如“裂纹青铜怀表”“红框全息倒计时界面”），用于特写转场与视觉记忆点 |
| **`@VOICE-NN`**（角色声线） | 与核心角色一一对应 | 音色性别年龄、语速倍率（写实 1.0x / 沙雕 1.15x–1.25x）、方言/口吻特征（适配 MiniMax-H3 原生音频参考或外部 TTS） |

### MiniMax-H3（Hailuo 3）多资产槽位守恒规则
- MiniMax-H3 单次生成最多支持 **12 个参考元素（最多 9 图、3 视频、3 音频）**，单镜 **5–15 秒**。
- 为保证生成稳定率：**单镜画面同框核心角色尽量 ≤ 2–3 人**（多人对峙改用“双人近景正反打 + 全景交代站位”），单镜引用资产总数建议 ≤ 5 个，严禁写“十个有名有姓的角色同框混战且每人同时说一句长台词”。

## 2. 「肌肉导演法」：把小说心理描写 100% 翻译成可拍画面

视频生成模型无法理解抽象心理总结词。写 `[画面]` 动作指令时，遵循一条铁律：**只写摄像机拍得到、麦克风录得到的具体物理变化**。

| 不可拍的“小说心理腔”（视频模型必呆滞） | 可直接生视频的「肌肉导演法」改写 |
|---|---|
| 他内心充满愤怒，暗自下定决心报复 | 画面：特写，他咬紧后槽牙，腮帮肌肉鼓起，右手死死攥皱桌上的合同纸，指节压出深折痕 |
| 她意识到自己被骗了，心中涌起一阵寒意 | 画面：近景，她笑容突然僵在嘴角，瞳孔微颤，低头盯着手机屏幕，指尖停在拨号键上方微微发抖 |
| 众人震惊不已，空气仿佛凝固了 | 画面：中景切两人特写，旁边端茶的亲戚手一滑，茶水洒在桌布上，围观三人同时张嘴转头盯向主角；音效：茶杯磕桌脆响，环境嘈杂声骤停 |
| 他早就看穿了大伯的阴谋，不动声色 | 画面：特写，他垂眼轻轻滑动手机，拇指点亮红色录音图标，随后平静把手机扣在桌面 |

> **如何保留必要的内心信息？** 确实需要交代主角精准算计或吐槽时，不要塞进 `[画面]` 里，直接放进 **`声音：@CHAR-01（OS/内心独白）：“……”`**，同时给角色一个清晰可拍的微表情或动作特写！

## 4. 视听剧本与算力成本体检镜子（`lint_script.py`）

完成试写或整批分集后运行（兼容 `@CHAR-01`/`[镜01｜0-7s]` 与 `char_01`/`Shot 01 | 124帧 (5.17s)`、`【镜 01｜00:00–00:03】` 等主流产线格式）：

```text
python <skill-dir>/scripts/lint_script.py --dir <项目根>/剧本 --genre <ai-drama|comic-drama|shadiao> --backend <minimax-h3|jimeng|general>
```

（若为抖音/推文旁白解说流沙雕动画，可加 `--allow-high-narration` 豁免红果 20% 旁白降档检查。）

### 体检维度（客观镜子，绝非必须清零的硬考题）

| 信号代码 | 体检内容 | 实际意义 |
|---|---|---|
| `hongguo_narration_over_20pct` / `season_hongguo_tier_drop_risk` | 统计单集旁白 + 心理独白/OS 占总口播字数比例（红线 **> 20%**）及全季超标集数（**≥ 3 集**） | 守住红果/抖音短剧创作者中心 **40×** 最高画风分成系数，防止被判定为 `10×` 动态解说漫剧 |
| `minimax_missing_mouth_lock` | `--backend minimax-h3` 且单镜出现 ≥2 个核心角色时，检查画面是否注明了“张嘴/闭嘴静态” | 防止 MiniMax-H3 原生影音多角色同框时串音或错误动嘴 |
| `duration_too_short` / `duration_too_long` | 结合显式时间轴、帧数/秒数与口播语速估测单集时长 | 防止单集低于 30 秒无法过审，或飙成 3 分钟拖死完播 |
| `speech_line_too_long` | 单句对白过长（`ai-drama`/`comic-drama` > 38 字；`shadiao` > 46 字） | 防竖屏大字字幕挡脸、AI 配音断气与口型漂移 |
| `unfilmable_mental_direction` | 画面指令中出现“内心充满/暗自盘算/看穿了一切”等不可拍心理词 | 提醒按「肌肉导演法」改回可见微表情/道具特写或移入 OS 轨 |
| `too_many_scenes` | 单集切换场景数 > 3 处 | 控换场算力预算，尽量收束在 1–2 个复用主场景 |
| `missing_cliffhanger_hint` | 集尾未检测到明确卡点/钩子或高张力落点 | 提醒检查集末能否拉起下一集连播 |
| `minimax_shot_over_15s` / `minimax_too_many_assets` | 单镜时长 > 15 秒，或单镜引用视觉资产 > 9 个 / 总资产 > 12 个 | 贴合 MiniMax-H3 单镜 5–15 秒与 12 参考槽位物理上限 |

## 5. 红果上传与双形态纯净导出（`export_drama.py`）

### 红果短剧创作者中心关键文本红线
- **剧名**：长度 **≤ 20 个字符**，严禁包含 `《》<>` 与空格，禁营销词（`【热播】【爆款】`），红果/抖音与封面剧名完全一致；
- **简介**：全剧简介建议 150–500 字，虚拟形象角色简介 10–100 字；
- **全剧时长**：首传及整剧 **≥ 20 分钟**（双周 TOP10 激励门槛），冲击「AI短剧创作计划」终极评奖 **≥ 30 分钟**，冲击更高版权系数 **≥ 60 / 120 分钟**；单集须 **≥ 30 秒**。

### 双形态导出命令

```text
# 1. 产线执行版（保留完整镜号、资产ID、口型锁定、Foley音效与可选资产总案）
python <skill-dir>/scripts/export_drama.py \
  --root <项目根> \
  --out-docx <项目根>/交付/<剧名>_产线剧本.docx \
  --out-txt <项目根>/交付/<剧名>_产线纯文本.txt \
  --title <剧名> \
  --format production \
  --include-bible

# 2. 红果送审 / 编剧投稿 / 存证纯净版（剔除机位分镜与技术ID，转为“第一集 / △动作 / 角色：台词 / （本集完）”标准格式）
python <skill-dir>/scripts/export_drama.py \
  --root <项目根> \
  --out-docx <项目根>/交付/<剧名>_送审纯净剧本.docx \
  --title <剧名> \
  --format clean-script
```

自动校验剧名长度与禁符号提醒，并拦截残留 `[待填]` 占位符，防止半成品误发。
